## Enterprise Rules

Enterprise Thread Foundation v1.0 is frozen.

Every mission-driven process should create or attach to an Enterprise Cognitive Thread.

Every thread must maintain station history.

Every station transition must be traceable.

Every thread should carry digital_thread_id when available.

Backward compatibility must be preserved.

No redesign without Architecture Review.
