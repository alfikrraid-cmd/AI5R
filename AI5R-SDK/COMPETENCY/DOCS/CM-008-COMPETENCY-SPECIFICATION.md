# AI5R Competency Foundation Specification

Version: 1.0

Status:
FROZEN

---

## Purpose

Competency is the canonical cognitive layer after Capability.

Capability defines what AI5R can do.

Competency defines how well AI5R performs that capability based on measured execution evidence.

---

## Canonical Definition

Competency is measured capability performance.

It must be derived from execution evidence, not declared manually.

## Enterprise Rules

Competency Foundation v1.0 is frozen.

Every competency must reference a capability_id.

Every competency should be based on execution evidence.

Every competency must be validated before registration.

Competency is not a declared skill.

Competency is measured performance.

Backward compatibility must be preserved.

No redesign without Architecture Review.
