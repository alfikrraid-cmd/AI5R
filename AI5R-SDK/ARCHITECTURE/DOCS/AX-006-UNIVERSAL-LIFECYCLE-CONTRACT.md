# AX-006 Universal Lifecycle Contract

Status: APPROVED DRAFT  
Layer: Architecture Foundation  
Purpose: Define universal lifecycle behavior for AI5R objects and relationships.

## 1. Definition

Lifecycle defines how an AI5R object or relationship changes state over time.

Lifecycle is not the object identity.

Lifecycle is a cross-cutting architectural concern applied to Universal Objects, Universal Relationships, Missions, Capabilities, Knowledge, Warehouse Records, Events, and Runtime entities.
