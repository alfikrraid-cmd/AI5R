## Manufacturing Principle

Nothing is created directly.

Everything is manufactured.

---

## Universal Manufacturing Components

Every manufacturing domain SHALL define:

- Specification
- Factory
- Artifact
- Registry
- Runtime

Evolution is optional but recommended.

- Knowledge

- Organization
- Product

- Decision

---

## Universal Rule

Specification defines WHAT.

Factory defines HOW.

Artifact is the manufactured output.

Registry stores artifacts.

Runtime operates artifacts.

Evolution continuously improves artifacts.
