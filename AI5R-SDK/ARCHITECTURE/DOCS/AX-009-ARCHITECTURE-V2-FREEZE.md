## Stable Contracts

All public APIs inside stable modules are frozen.

Breaking changes are prohibited.

Backward compatibility is mandatory.

---

## Extension Rule

Future evolution SHALL occur by:

- adding new modules
- adding optional interfaces
- extending implementations

Existing public contracts SHALL NOT be removed.

---

## AI5R Philosophy

AI5R is a Digital Factory Operating System.

Every component SHALL behave as a production-grade subsystem.

Architecture stability has higher priority than feature velocity.
