# AI5R Capability Foundation Specification

Version: 1.0

Status:
FROZEN

---

## Purpose

Capability is the canonical cognitive layer after Knowledge.

Knowledge defines what AI5R knows.

Capability defines what AI5R can do.

---

## Canonical Definition

Capability is an executable enterprise ability that uses knowledge to perform a class of work.

## Enterprise Rules

Capability Foundation v1.0 is frozen.

Every capability must be registered before execution.

Every capability must be validated before registration.

Capability execution must go through CapabilityRuntime or an approved Factory Station.

Backward compatibility must be preserved.

No redesign without Architecture Review.
