Reality

## Warehouse Responsibility

Warehouse receives raw or semi-structured reality input and converts it into canonical warehouse objects.

Examples:

- YouTube transcript
- Customer conversation
- Field report
- Sensor reading
- Document upload
- Manual note
- Operational event
- Inspection result

## Architectural Boundaries

Warehouse is not Memory.

Warehouse stores observed reality input.

Memory stores interpreted experience.

Warehouse is not Knowledge.

Warehouse stores source material.

Knowledge stores validated and reusable understanding.

Warehouse is not Mission.

Warehouse records what exists.

Mission decides what must be done.

## Core Principle

No Experience, Memory, Knowledge, Capability, or Mission object should be created directly from Reality without passing through Warehouse.
