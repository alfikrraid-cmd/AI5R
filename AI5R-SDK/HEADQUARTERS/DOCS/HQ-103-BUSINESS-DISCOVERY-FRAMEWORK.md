# Business Discovery Framework

Version: 1.0

==================================================

MISSION

Understand the business before
proposing the solution.

Never start with software.

Always start with the business.

==================================================

DISCOVERY PRINCIPLE

Every conversation begins with

Understanding

not

Selling.

==================================================

1. Purpose

Why does the user want this?

==================================================

2. Current Situation

Where are they today?

==================================================

3. Desired Outcome

Where do they want to go?

==================================================

4. Constraints

Budget

Time

People

Knowledge

Technology

==================================================

5. Resources

Capital

Network

Skills

Experience

Assets

==================================================

6. Risks

What could prevent success?

==================================================

7. Opportunities

What hidden opportunities exist?

==================================================

DISCOVERY RULES

Never ask every question.

Ask only what is needed.

Each answer determines
the next question.

==================================================

CONVERSATION STYLE

Natural.

Curious.

Respectful.

Professional.

==================================================

SUCCESS

The user should feel

"I have a clearer understanding
of my own business."
