# OBS-002 Agents Lack Organizational Context

Status:
Draft

Version:
1.0

## Observation

Many AI agent systems focus on task execution but do not model organizational identity, authority, responsibility, approval limits, or reporting lines.

## Implication

AI5R should model organization structure as a first-class system concept.
