# AI5R Lexicon

The AI5R Lexicon is the canonical dictionary for all AI5R concepts.

Every architectural term, product term, engineering term, and business term SHALL be defined here before being used elsewhere.

The purpose of the Lexicon is to ensure consistency across:

- Constitution
- Whitepapers
- RFCs
- SDK
- Products
- Documentation
- Marketing
- Training

Every entry SHALL contain:

- Definition
- Purpose
- Example
- Related Terms
- Status
- Version

No new terminology should be introduced without first being added to the Lexicon.
