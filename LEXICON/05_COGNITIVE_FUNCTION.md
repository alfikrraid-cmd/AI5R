# Cognitive Function

Status:
Draft

Version:
1.0

## Definition

A Cognitive Function is a thinking function performed by a Position or Digital Employee.

It defines how intelligence is applied, not what specific task is executed.

## Purpose

To separate thinking behavior from job title.

## Examples

- Planner
- Reviewer
- Strategist
- Advisor
- Approver
- Observer
- Evaluator
- Communicator

## Related Terms

- Position
- Capability
- Digital Employee
