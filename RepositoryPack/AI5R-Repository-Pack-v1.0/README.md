# AI5R

**Artificial Intelligence Five Revolution**

AI5R is an autonomous AI Software Engineering Platform designed to build systems that build businesses.

## Start Here

Read in this order:

1. `BOOTSTRAP/LOAD.md`
2. `BOOTSTRAP/CURRENT_STATE.md`
3. `BOOTSTRAP/SESSION.md`
4. `CONSTITUTION/00_IDENTITY.md`
5. `CONSTITUTION/01_MISSION.md`

## Current Status

AI5R is transitioning from chat-based ideation into repository-based engineering.

The repository is the **Single Source of Truth**.

## Repository Roles

- `CONSTITUTION/` — canonical identity, mission, values, thinking model, and operating laws.
- `BOOTSTRAP/` — session loader, current state, sprint, and next actions.
- `ADR/` — architecture decision records.
- `CORE-SERVICES/` — kernel, memory, git, artifact, DNA, reviewer, and related platform services.
- `FACTORIES/` — developer, book, activity, website, video, and OSA factories.
- `REGISTRY/` — artifact registry, workflow registry, prompt registry, and manifests.
- `SYSTEM/` — system prompts derived from the Constitution.
